Structure

Radiant.Inelastic_Collision — Type

Inelastic_Collision

Structure used to define parameters for production of multigroup inelastic collisional cross-sections.

Mandatory field(s)

  • N/A

Optional field(s) - with default values

  • interaction_types::Dict{Tuple{DataType,DataType},Vector{String}} = Dict((Positron,Positron) => ["S"],(Positron,Electron) => ["P"],(Electron,Electron) => ["S","P"]) : Dictionary of the interaction processes types, of the form (incident particle,outgoing particle) => associated list of interaction type, which values correspond:
    • (Positron,Positron) => ["S"] : scattering of incident positrons
    • (Electron,Electron) => ["S"] : scattering of incident electrons
    • (Positron,Electron) => ["P"] : production of electrons by incident positrons
    • (Electron,Electron) => ["P"] : production of electrons by incident electrons

Radiant.set_ecut — Method
set_ecut(this::Inelastic_Collision,particle::Type,energy::Real)

To set the energy above which the corrected Bethe formula is used for a given particle, and below which the stopping power is taken from the low-energy branch.

Lowering it extends the Bethe formula into a region where its corrections are less well determined; the shell-correction tables stop at a tabulated γ and raise an error naming this setter when they run out.

Input Argument(s)

  • this::Inelastic_Collision : inelastic collision structure.
  • particle::Type : particle type, one of Electron, Positron, Muon, Antimuon, Proton, Antiproton or Alpha.
  • energy::Real : cutoff energy [in MeV].

Output Argument(s)

N/A

Examples

julia> inelastic_collision = Inelastic_Collision()
julia> inelastic_collision.set_ecut(Proton,1.0)

Radiant.set_emax — Method
set_emax(this::Inelastic_Collision,particle::Type,energy::Real)
set_emax(this::Inelastic_Collision,particle::Type,mode::String)

To set the energy of the stopping-power maximum of the analytic low-energy extension.

Emax is read only inside that extension and is meaningful only there: both of its branches have zero slope at Ei/Emax = 1, so Emax is where the extension puts the stopping-power maximum. Nothing at or above Ecut changes, and neither does the "icru49" low-energy branch, which does not use it.

Passing "f" selects emax_stopping_maximum, a power-law fit in the mean atomic number to the measured maximum of all 92 elements against SRIM-2013. A single constant asserts the same peak energy in hydrogen as in uranium, where the real peak runs 41-164 keV for protons and 0.42-1.19 MeV for alphas. "f" is accepted for Proton and Alpha only; there is no Z-dependent fit for the others.

Input Argument(s)

  • this::Inelastic_Collision : inelastic collision structure.
  • particle::Type : particle type.
  • energy::Real : energy of the stopping-power maximum [in MeV].
  • mode::String : "f", to select the Z-dependent fit.

Output Argument(s)

N/A

Examples

julia> inelastic_collision = Inelastic_Collision()
julia> inelastic_collision.set_emax(Proton,"f")
julia> inelastic_collision.set_emax(Alpha,0.9)

Radiant.set_low_energy_model — Method
set_low_energy_model(this::Inelastic_Collision,model::String)

To set the model used for the stopping power below Ecut.

  • analytic : analytical extension anchored on the value and the slope of the Bethe branch at Ecut. Smooth at the join, but it extrapolates from that single anchor and its error grows with distance from it.
  • icru49 : the empirical form of ICRU Report 49, attributed there to Andersen and Ziegler, with per-element coefficients fitted to SRIM-2013. The low branch exponent is fitted per element rather than pinned at 0.45, which is what removes the separate sqrt(E) branch the pinned version carries below 10 keV. It is confined to [0.30, 0.80], a departure from the parametrization as published: unconstrained, seven of the 92 proton fits ran to 0.8-1.31 with 22-43% error extrapolating below the fitting window.

The default is analytic, and it stays the default in this change: that the evidence favours the fitted branch does not make a default swap part of it.

Measured against NIST PSTAR/ASTAR below Ecut over the 74 ICRU 49 materials, median deviation goes from 18.72% to 2.67% for protons and 26.40% to 3.60% for alphas. Against the same form with the exponent pinned at 0.45 the improvement is decisive for alphas and close to a coin flip for protons – 3.33% to 2.67%, with the whole proton gain coming from below 10 keV, where the fitted exponent replaces the pinned form's bolted-on sqrt(E). That region is where PSTAR and ASTAR are themselves fits to experiment in this same empirical form, so the comparison is between two empirical fits of one functional form and not between a model and theory.

10 keV is the floor of validity. Below about 5 keV this branch is badly wrong for some elements – helium worst, 153% median below 10 keV – and no choice of exponent fixes it.

Above Ecut the fitted form is blended onto the Bethe branch over one octave, so that the handover is C¹ rather than leaving a step of up to 13.6% in the CSD operator.

Below Ecut with icru49 selected, sp computes Sr = Stot - Sc where Stot is a fit to SRIM's total electronic stopping while Sc comes from the analytic heavy-particle differential cross-section, so the soft/catastrophic split is approximate in that region. In practice it rarely bites – a 750 keV proton can transfer at most about 1.6 keV to an electron, so Sc is zero unless the electron group structure reaches below that – and it is not new, since the analytic extension is not a Bethe evaluation either.

The fitted table covers Z = 1-92, protons and alphas only. Any other particle, or any element outside that range, falls back to the analytic extension silently.

Input Argument(s)

  • this::Inelastic_Collision : inelastic collision structure.
  • model::String : low-energy model, "analytic" or "icru49".

Output Argument(s)

N/A

Examples

julia> inelastic_collision = Inelastic_Collision()
julia> inelastic_collision.set_low_energy_model("icru49")

Reference(s)

  • ICRU Report 49 (1993), Stopping Powers and Ranges for Protons and Alpha Particles.
  • Andersen and Ziegler (1977), Hydrogen: Stopping Powers and Ranges in All Elements.
  • Salvat (2022), Bethe stopping-power formula and its corrections. Eqs. (134)-(136), for the free-exponent parametrization and the fitting prescription.
source
Radiant.set_low_energy_source — Method
set_low_energy_source(this::Inelastic_Collision,source::String)

To choose which coefficients the fitted low-energy branch reads.

  • srim : fitted to SRIM-2013, all 92 elements from one fit.
  • iaea : fitted to the IAEA electronic stopping power database — the compiled experimental literature, 720 references, publications from 1928 to 2025. Same form, same units, same phase convention, same a2 bound; only the numbers differ.

It is inert unless set_low_energy_model("icru49") is also selected. There are no coefficients in the analytic branch to choose between, and results are bit-identical between the two sources there.

iaea is a partial override on top of the SRIM table, not a table in its own right: it covers 41 elements for protons and 30 for alphas, and it is resolved per element at the point of use, so a compound routinely draws from both at once. An element is missing only because the measurements cannot determine the form — no points on one side of the stopping maximum, too few points, or nothing reaching Ecut — and every element it omits is served by the SRIM entry through the same lookup. So iaea never fails, never warns, and leaves most materials untouched.

Each entry carries n_references and a leave-one-reference-out cross-validated error under ["quality"], and those are the numbers to read before relying on one. The cross-validated median is 4.38% for protons and 3.38% for alphas, against in-sample medians of 2.83% and 2.03%; the tail is real and is not hidden — terbium fits its own alpha points well and misses by 44% when a reference is held out. Radiant does not gate on these numbers: which entries to trust is the user's judgement, and a filter applied here would be invisible to them.

This is a choice of reference, not an upgrade. Scored against NIST PSTAR/ASTAR, which neither table was fitted to, iaea is closer for 11 of 23 elements for protons and 6 of 19 for alphas, and the median is worse for both — 1.72% to 2.38% and 1.85% to 3.13%. The gains and the losses are both large where they occur: Pt 10.68% to 3.67% against Pb 2.96% to 7.19% for protons, Ar 1.42% to 0.42% against Ti 1.04% to 11.27% for alphas. ICRU 49 is itself an evaluation of experiment in this same functional form, so this is two empirical fits weighing the same disagreeing literature differently, not a model scored against theory: srim tracks ICRU 49 more closely because SRIM and ICRU 49 are two evaluations by overlapping communities of the same older measurements, while iaea tracks the current compiled database, which includes measurements neither of them saw. The measurements disagree among themselves by 14-17%.

The honest reason to select iaea is wanting elemental stopping tied to the measurement compilation rather than to SRIM's evaluation of it, or working on an element where the two disagree and having a reason to trust the measurements. On the evidence above, for alphas it is usually worse.

The default stays srim: it is the only source covering all 92 elements from one fit, and defaulting to a partial one would put a provenance seam in the middle of the table where a trend across Z could no longer be told from a change of data source.

Input Argument(s)

  • this::Inelastic_Collision : inelastic collision structure.
  • source::String : coefficient source, "srim" or "iaea".

Output Argument(s)

N/A

Examples

julia> inelastic_collision = Inelastic_Collision()
julia> inelastic_collision.set_low_energy_model("icru49")
julia> inelastic_collision.set_low_energy_source("iaea")

Reference(s)

  • IAEA, Electronic Stopping Power of Matter for Ions (database), https://www-nds.iaea.org/stopping/. Sole source of the "iaea" coefficients.

Radiant.set_is_bragg_additivity — Method
set_is_bragg_additivity(this::Inelastic_Collision,is_bragg_additivity::Bool)

To build the stopping power of a compound from its elements rather than from its own composition. Each element is evaluated separately and the results are combined with mass fractions, S = Σⱼ ωⱼ Sⱼ, which is what mass stopping power is additive in.

Every element is evaluated at the compound density, because the density effect in a compound is set by the compound's electron density and not by what the pure element would do on its own.

Scope: the Bethe branch only. The fitted icru49 low-energy branch is already unconditionally additive whatever this flag says, so scoping the flag here is what stops it meaning different things in different energy regions. With the analytic model each element's extension anchors to that element's own Bethe value and slope at Ecut.

Enabling this overrides the tabulated compound mean excitation energy. effective_mean_excitation_energy returns the ICRU value for canonical compounds — 75 eV for liquid water — before falling back to additivity. Building water from H and O elementwise means each element carries its own I and that 75 eV never enters. For electrons this is a visible shift, and in the opposite direction from what a user who trusts ICRU would want, so it is a choice to be made knowingly.

Note also that any additivity-based kernel misses NIST's liquid water by about 28% at 1 keV and 18% at 100 keV. Applying additivity to NIST's own hydrogen and oxygen tables reproduces the same gap, so that is the assumption failing rather than the implementation.

Applies to all particles.

Input Argument(s)

  • this::Inelastic_Collision : inelastic collision structure.
  • is_bragg_additivity::Bool : activate (true) or deactivate (false) Bragg additivity.

Output Argument(s)

N/A

Examples

julia> inelastic_collision = Inelastic_Collision()
julia> inelastic_collision.set_is_bragg_additivity(true)

Radiant.set_use_srim_sp — Method
set_use_srim_sp(this::Inelastic_Collision,use_srim_sp::Bool)

To replace the computed electronic stopping power with SRIM-2013's own tabulated values, mixed from the elements in mass fractions and taken in the material's declared phase. On this path bethe is not called at all for the electronic term.

The point is fidelity to SRIM, not accuracy. Turn it on to reproduce SRIM numbers — to compare against a SRIM-based workflow, or to feed a code that was tuned on them. Everything else in the stopping-power path is about getting the physics right; this one is about getting SRIM right, and the two are not the same thing.

Supported for Proton and Alpha only, over 0.1 keV to 1 GeV for protons and 0.1 keV to 4 GeV for alphas, Z = 1 to 92. Anything outside that raises rather than quietly falling back, because a silent fallback puts a discontinuity in the middle of a stopping-power curve where the user cannot see it. A user who sets this on a mixed electron/proton problem needs to be told, not to get Bethe for the electrons and SRIM for the protons without knowing which is which.

SRIM's compound correction is deliberately not applied and cannot be set. It is a property of the molecule rather than of the interaction, so one setting here would apply one molecule's bond correction to every material in the geometry; and the numbers are in no shipped SRIM data file, only in the GUI's Compound Dictionary. For a molecular target the correction SRIM would have applied reaches about 6% below 1 MeV — liquid water is -6.00% flat from 10 keV to 400 keV — fading out above about 2.5 MeV/u. So below a few MeV this reproduces SRIM run on a composition, not SRIM's compound library entry.

SRIM has no Fermi density effect at all, so above roughly 500 MeV/u these tables are wrong in a way that grows with energy: for liquid water the density effect removes about 1.8% of the stopping number at 2 GeV and 8.5% at 10 GeV, and none of it is in SRIM. This is the wrong switch for high-energy work.

Enabling it supersedes set_ecut, set_emax, set_low_energy_model, set_low_energy_source and set_is_bragg_additivity for the electronic stopping power: none of them are consulted, because none of them describe what SRIM did. They stay set, and the combination is not an error — a user who has the fitted branch configured and then sets this is switching sources.

It is itself superseded, per material and per particle, by a user table registered with Material.set_stopping_power.

Input Argument(s)

  • this::Inelastic_Collision : inelastic collision structure.
  • use_srim_sp::Bool : activate (true) or deactivate (false) the SRIM tables.

Output Argument(s)

N/A

Examples

julia> inelastic_collision = Inelastic_Collision()
julia> inelastic_collision.set_use_srim_sp(true)

Reference(s)

  • Ziegler, Ziegler and Biersack (2010), SRIM - The Stopping and Range of Ions in Matter.
